# Metodología · Gamificación con Octalysis

Página explicativa de la metodología Octalysis aplicada al trabajo: qué es la
gamificación, los 8 motivadores, las dos lecturas del octágono, las 4 fases del
viaje y qué premiar (modelo SAPS), con un diagnóstico al final.

Sitio estático (HTML + CSS + JS, sin build) publicado con GitHub Pages.

- `index.html` — la página
- `styles.css` — estilos propios
- `vendor/galilei-base.css` — CSS base de galileilearning.com
- `app.js` — interacciones y diagnóstico
- `assets/` — imágenes e íconos
